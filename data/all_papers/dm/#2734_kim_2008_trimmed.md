# 2. Methods
## 2.1. Study design

This is a quasi-experimental design with pre- and followup tests for 12 months. Participants were recruited from the endocrinology outpatient department of tertiary care hospital located in an urban city of South Korea. The hospital is a university-affiliated medical center that has 800 beds.

# 2.2. Outcome measures
Before the intervention, demographic variables, glycosylated hemoglobin ( { \mathrm { H b } } \mathsf { A } _ { 1 } \mathsf { c } ), fasting plasma glucose (FPG), and 2-h post-prandial test (2HPPT) were measured as pre-test data. The { \mathrm { H b } } \mathsf { A } _ { 1 } \mathsf { c } _ { \mathrm { : } }, FPG, and 2HPPT were measured again 3, 6, 9, and 12 months later. Patients’ blood was drawn from the veins for { \mathrm { H b A } } _ { 1 } { \mathsf { c } } , { \mathrm { F P G } } ,and 2HPPT measurement. { \mathrm { H b } } \mathsf { A } _ { 1 } \mathsf { c } ,, FPG, and 2HPPT were measured in a laboratory of the university-affiliated medical center. 2HPPT were measured 2 h after consumption prescribed diabetic meal. { \mathrm { H b } } { \mathrm { A } } _ { 1 } { \mathrm { c } }was determined by a high-performance liquid chromatography technique using the Variant II (Bio-Rad, Montreal, Quebec, Canada). FPG and 2HPPT were analyzed by the glucose oxidase method using a Hitachi 7600 (Hitachi, Japan).

## 2.3. Sample

The data were collected from January 2003 to December 2006. Diabetes was diagnosed according to the ADA criteria [9]. Obese was defined as BMI > 23 kg/m2 [10]. The selection criteria required that participants should be able to perform blood glucose self-testing and self-injection of medication in case of insulin prescribed, input the website, and have their

own cellular phone. Patients were excluded if they had a clinical history of a renal insufficiency with a creatinine level >1.5 mg/dl, or had been using insulin pumps.

For unpaired t-test (for an effect size of 0.60, at a power of 0.80 and at an alpha level of 0.05), 45 subjects in each group were required [11] in order to ensure an adequate trial for 1% reduction of { \mathrm { H b } } { \mathsf { A } } _ { 1 } { \mathsf { c } }levels at post-test compared with pre-test [12]. However, for repeated measures analysis of variance (for an effect size of 0.60, at a power of 0.80 and at an alpha level of 0.05), 34% of unpaired t-test samples ( \mathrm { r h o } = 0 . 6 0 , one time of pre-test, four times of post-test), 15 subjects in each group were required [11]. HbA1c is a more comprehensive measure of total glycemic exposure than FPG and highly correlated with the presence of diabetic micro vascular complications in prospective studies. Therefore, HbA1c may be the most suitable predictor of glycemia related complications [13]. A total of 40 patients met the above criteria and agreed to participate. They were randomized by random permuted block design using a random number table, and assigned to one of two groups, either intervention (n = 20) or control (n = 20). Only 34 subjects completed the entire study, 18 interventions and 16 controls. In intervention group, two subjects failed to record their glucose levels for more than four weeks on the provided web site (http://www.biodang.com). As for the control group, four subjects refused to participate before completing the one year.

## 2.4. A short message service

The goal of the intervention was to decrease body weight and maintain blood glucose levels ( \mathtt { H b A } _ { 1 } { \mathsf { c } }value < 7%) within a normal range. Before the intervention, each patient was instructed, for 30 min by a researcher, about inputting data into the website. Patients in the intervention group contacted our website and logged in whenever it was convenient for them. Patients in the intervention group in our study could contact our website at any place where Internet access was possible by personal cellular phone or wired Internet. They then sent their self-monitored blood glucose levels and drug information, including the kinds and dosages of insulin and oral anti-diabetic medication that they used for diabetes control. These data were transported to our Internet server system, and automatically displayed on the individual electronic chart on our homepage. Patients were able to see the recommendations from the researcher, as well as the laboratory data, on our website.

The researcher is a diabetic educator, a professor of nursing college, and a member of this application development project team. The researcher could view the information on each patient, including the blood glucose levels, medication and details of some events that were provided by the patient. In addition to this information, the researcher could also view basic personal history, including historical data, family history, smoking habits, BMI, blood pressure and baseline laboratory data. After integrating the above information, the researcher sent optimal recommendations to each patient, by both the cellular phone and the Internet weekly. For example, recommendations included: “Please, decrease the longacting insulin by two units”; “Please add one tablet of sulfonylurea in the evening”; “Lack of exercise may be the cause of the

aggravated glucose level” or “Your glucose control seems to be good” (Fig. 1). The researcher provided the intervention for 12 months. The 12 months of intervention consisted of continuous education and reinforcement of diet, exercise, medication adjustment, as well as frequent self-monitoring of blood glucose levels. The researcher could adjust medications after reviewing the blood glucose log and discussing glucose values with the patients. All medication adjustments were communicated to the subjects’ diabetes doctor. If a patient had not forwarded a blood glucose level for more than 1 week, a warning message was sent. If despite the warning messages, individuals that had not recorded glucose levels for more than four consecutive weeks, were withdrawn from the intervention group.

Participants in the intervention and the control groups met the endocrinologist specialist four or five times during the 12 months which was the one diabetes doctor involved in this study for the intervention and control groups.

As customary in our outpatient clinic for patients with diabetes, when the patients in the control group visited our center, they were provided with recommendations about medication, medication dosage, and lifestyle modification by the endocrinologist specialist. When the doctor chose to consult with the patient to disclose particular information, or if the patient wished, the nurse or dietitian came to aid with more individualized and detailed information relating to lifestyle modification.

## 2.5. Statistical analysis

The data were analyzed using the SAS (version 8.12, SAS institute, Cary, North Carolina) program. Chi square test, t-test, and Fisher’s exact tests were used to test for the homogeneity of demographic and clinical characteristics between the intervention and control groups. Repeated-measures analysis of variance (ANOVA) was used to determine the difference

between groups and over time. When a significant difference was found by repeated-measures ANOVA, paired t-tests with Bonferroni correction were applied to identify specific differences.

## 2.6. Ethical issues

For ethical considerations, the research protocol was approved by the Medical Research Ethics Committee of the university hospital. Written consent was obtained from those patients who agreed to participate in the study. Anonymity and confidentiality were guaranteed to participants.
